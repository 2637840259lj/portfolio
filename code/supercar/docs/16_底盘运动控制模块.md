# 底盘运动控制模块（Car）

## 概述

这是整个项目最核心的模块，实现了 **底盘运动控制状态机**、**路口检测与识别**、**绕圈任务管理** 和 **自动停车逻辑**。它协调灰度传感器、IMU、PID 控制器和电机驱动，完成从循迹 → 转弯 → 圈数计数 → 终点停车的完整竞赛流程。

## 全局变量

### 任务控制结构体 g_MissionControl

```c
LineFollowControl_t g_MissionControl = {
    .target_laps = 1,                   // 默认目标 1 圈
    .current_laps = 0,                  // 当前已完成圈数
    .current_lap_turns = 0,             // 当前圈已完成转弯次数
    .is_running = false,               // 任务未运行
    .first_turn_detected = false,       // 未检测到第一个路口
    .second_turn_detected = false,      // 未检测到第二个路口
    .all_laps_completed = false,        // 圈数未完成
    .turn_direction = 1                 // 默认左转
};
```

### 其他全局变量

| 变量 | 类型 | 说明 |
|------|------|------|
| `chassis_state` | ChassisState_e | 底盘当前状态：循迹/左转/右转/停车 |
| `g_turnControl` | TurnControl_t | 转弯控制参数（开始时间、阶段、激活标志） |

## 状态枚举

### ChassisState_e（底盘状态）

| 状态 | 含义 | 对应的 run_mode |
|------|------|-----------------|
| `STATE_LINE_FOLLOW` | 循迹模式 | 1 |
| `STATE_LEFT_TURN` | 左转路口处理 | 2 |
| `STATE_RIGHT_TURN` | 右转路口处理 | 2 |
| `STATE_STOP` | 停车模式 | 0 |

### LineType_e（路口类型）

| 类型 | 数字量模式 | 含义 |
|------|------------|------|
| `LINE_STRAIGHT` | 0x18/0x1C/0x38 | 直线/略有偏移 |
| `LINE_LEFT` | 0x0F | 左转路口（只有左边有黑线） |
| `LINE_RIGHT` | 0xF0 | 右转路口（只有右边有黑线） |
| `LINE_CROSS` | 0xFF | 十字路口（全部看到黑线） |
| `LINE_T_LEFT` | 0x1F | T 字路口（左半边全黑） |
| `LINE_T_RIGHT` | 0xF8 | T 字路口（右半边全黑） |
| `LINE_LOST` | 0x00 | 完全脱线 |

### TurnPhase_e（转弯阶段）

| 阶段 | 含义 | 持续时间 |
|------|------|----------|
| `TURN_PHASE_BLIND` | 圆弧盲转阶段 | 100ms + 角度 < 10° |
| `TURN_PHASE_SEARCH` | 寻线阶段 | 直到灰度传感器探测到黑线 |

## 绕圈任务参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `RETURN_STOP_COMPENSATION` | 420 脉冲 | 停车提前量（约 5.9cm） |
| `side_length_pulses` | 7130（约 100cm） | 正方形边长默认值（第一圈校正前） |

## API 函数详解

### 1. CarInit()

**功能**：底盘初始化（当前为空函数，PID 和传感器初始化在 main 中完成）。

```c
int CarInit(void);
```

| 返回值 | 说明 |
|--------|------|
| 0 | 成功 |

### 2. CarTask() ★ 核心状态机

**功能**：底盘任务主循环，在 `main()` while(1) 中以 10ms 周期调用。

```c
void CarTask(void);
```

**状态机流程**：

```
                   ┌─────────────────────────┐
                   │    STATE_LINE_FOLLOW     │ ← 循迹直行
                   │    (run_mode = 1)        │
                   └──────────┬──────────────┘
                              │ 检测到路口
                   ┌──────────▼──────────────┐
            ┌──────┤   STATE_LEFT/RIGHT_TURN  │ ← 转弯
            │      │   (run_mode = 2)         │
            │      └──────────┬──────────────┘
            │                 │ 寻线成功
            │      ┌──────────▼──────────────┐
            └──────┤   STATE_LINE_FOLLOW     │ ← 继续循迹
                   │   (count turns/laps)    │
                   └──────────┬──────────────┘
                              │ 圈数完成
                   ┌──────────▼──────────────┐
                   │     STATE_STOP           │ ← 回到起点停车
                   └─────────────────────────┘
```

**STATE_LINE_FOLLOW 内部逻辑**：
1. 如果所有圈数已完成：检查是否到达起点并停车
2. 如果检测到路口（左转/右转/T字路口）：
   - 第一次路口：记录起点偏移量、判定绕圈方向
   - 第二次路口：测量正方形边长
   - 根据绕圈方向决定左转或右转
   - 目标角度 = 当前绝对角度 + 90°（锁定到 0/90/180/270 网格）
3. 切换到转弯状态

**STATE_LEFT_TURN / STATE_RIGHT_TURN 内部逻辑**：
1. 盲转阶段：等待 100ms + 角度偏差 < 10°
2. 寻线阶段：灰度传感器探测到黑线（`digital & 0x7E`）→ 切回循迹
3. 寻线成功后：记录转弯结束位置、更新圈数和转弯计数

### 3. LineFollow_SetTargetLaps()

**功能**：设定目标圈数（1~10），蜂鸣器给出圈数反馈。

```c
void LineFollow_SetTargetLaps(int laps);
```

| 参数 | 说明 |
|------|------|
| `laps` | 目标圈数（1~10），超出范围无效 |

### 4. Car_MissionStart()

**功能**：启动绕圈任务。重置所有计数器，记录起点位置，切换到循迹状态。

```c
void Car_MissionStart(void);
```

**内部操作**：
- 重置圈数/转弯计数
- 设置默认边长（7130 脉冲 ≈ 100cm）
- 记录起点编码器值
- 设置运行标志和绿灯

### 5. Car_MissionStop()

**功能**：停止底盘运动。清除运行标志，切换到停车模式。

```c
void Car_MissionStop(void);
```

## 内部函数详解

### Get_Gray_Digital()


| 返回值 | 说明 |
|--------|------|
| uint8_t | 8 位数字量（取反后：1=黑, 0=白） |

### DetectIntersectionType()

**功能**：根据数字量模式判定路口类型。

```c
LineType_e DetectIntersectionType(uint8_t digital);
```

| 参数 | 说明 |
|------|------|
| `digital` | 8 位数字量 |
| **返回值** | 路口类型枚举值 |

**判定表**：

| 数字量 | 二进制 | 判定结果 |
|--------|--------|----------|
| 0x18 | `00011000` | 直线 |
| 0x1C | `00011100` | 直线 |
| 0x38 | `00111000` | 直线 |
| 0x0F | `00001111` | 左转 |
| 0xF0 | `11110000` | 右转 |
| 0xFF | `11111111` | 十字路口 |
| 0x1F | `00011111` | T 字左 |
| 0xF8 | `11111000` | T 字右 |
| 0x00 | `00000000` | 完全脱线 |

| 返回值 | 说明 |
|--------|------|

## 转弯算法核心

### 角度累积制

```c
// 左转时：
pidAngle.target += 90.0f;
// 右转时：
pidAngle.target -= 90.0f;
```

目标角度在绝对网格上累加（0 → -90 → -180 → 90 → 0），累积误差不传播到下一圈。

### 圆弧差速模型（在 empty.c 的 Angle_Loop 中）

转弯时小车以定半径 R=15.5cm 做圆弧运动：
- 外轮速度 ≈ 25 cm/s
- 中心线速度 ≈ 18 cm/s
- 内轮速度 ≈ 11 cm/s
- 角度偏差 > 6° 时完全屏蔽 PID 微调（保证圆弧纯净）
- 角度偏差 < 6° 时逐步引入 PID 修正以锁定目标角度

## 圈数计算

```c
// 每 4 个弯 = 1 圈
if (++current_lap_turns >= 4) {
    current_lap_turns = 0;
    current_laps++;
}
```

## 终点停车

正方形赛道最后一圈跑完后，小车通过编码器里程计算行驶距离，当到达起点位置减去补偿量（420 脉冲）时自动停车。

```c
int32_t target_dist = side_length_pulses - start_to_first_turn_pulses - RETURN_STOP_COMPENSATION;
if (current_dist >= target_dist) Car_MissionStop();
```
