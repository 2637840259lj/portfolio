# 灰度传感器驱动模块（No MCU Ganv Grayscale Sensor）

## 概述

本模块驱动 **8 通道灰度传感器阵列**，通过 3 线 GPIO 控制 CD4051 模拟多路复用器，使用单路 ADC 分时采样 8 个红外探头的反射光强度。提供模拟量采集、数字量阈值判定、归一化处理以及 PID 循迹用的加权质心偏差计算。

## 硬件引脚映射

| 功能 | 信号 | MCU 引脚 | 配置 |
|------|------|----------|------|
| 多路选择位 0 | AD0 | PA28 | GPIO 输出，控制 CD4051 的 A 通道 |
| 多路选择位 1 | AD1 | PA29 | GPIO 输出，控制 CD4051 的 B 通道 |
| 多路选择位 2 | AD2 | PA30 | GPIO 输出，控制 CD4051 的 C 通道 |
| ADC 模拟输入 | CH3 | PA24 | ADC12_0 通道 3，12bit 分辨率 |

### ADC 配置参数

| 参数 | 值 |
|------|-----|
| ADC 外设 | ADC0 |
| 采样通道 | ADC12_INPUT_CHAN_3 |
| 分辨率 | 12 bit（0~4095） |
| 参考电压 | VDDA（3.3V） |
| 采样时钟分频 | ÷8 |
| 时钟源 | SYSOSC（32MHz，24~32MHz 范围） |
| 采样时间 | 2μs |
| 工作模式 | 自动重复 + 软件触发 |

### 多路复用器控制宏

```c
#define Switch_Address_0(i)  ((i)?(DL_GPIO_setPins(...AD0))   : (DL_GPIO_clearPins(...AD0)))
#define Switch_Address_1(i)  ((i)?(DL_GPIO_setPins(...AD1))   : (DL_GPIO_clearPins(...AD1)))
#define Switch_Address_2(i)  ((i)?(DL_GPIO_setPins(...AD2))   : (DL_GPIO_clearPins(...AD2)))
```

3 个 GPIO 组成 3bit 地址（0~7），选择 8 个探头之一接入 ADC。

## 数据结构

### No_MCU_Sensor

```c
typedef struct {
    unsigned short Analog_value[8];      // 8 通道原始模拟量（12bit: 0~4095）
    unsigned short Normal_value[8];      // 8 通道归一化后的值
    unsigned short Calibrated_white[8];  // 白色标定基准值
    unsigned short Calibrated_black[8];  // 黑色标定基准值
    unsigned short Gray_white[8];        // 判定为白色的动态阈值（靠近白）
    unsigned short Gray_black[8];        // 判定为黑色的动态阈值（靠近黑）
    double Normal_factor[8];             // 归一化比例系数
    double bits;                         // ADC 满量程（12bit=4096.0）
    unsigned char Digtal;                // 8 位数字量结果（每一位对应一个探头）
    unsigned char Time_out;              // 采样超时设定
    unsigned char Tick;                  // 计时器计数
    unsigned char ok;                    // 初始化完成标志
} No_MCU_Sensor;
```

### 全局传感器实例

```c
No_MCU_Sensor g_GraySensor;  // 全局灰度传感器对象
```

## 出厂标定值（硬编码）

```c
// 白纸基准（8 个探头在白纸上的 ADC 均值）
uint16_t white[8] = {2414, 3350, 2865, 2689, 3200, 2863, 2671, 3313};
// 黑线基准（8 个探头在黑线上的 ADC 均值）
uint16_t black[8] = { 163,  141,  167,  181,  180,  160,  153,  157};
```

> **注意**：更换场地或传感器位置后需要重新标定。标定值影响归一化系数和数字量阈值。

## API 函数详解

### 1. No_MCU_Ganv_Sensor_Init_Frist()

**功能**：传感器结构体初步清零（内部函数，由 `No_MCU_Ganv_Sensor_Init` 调用）。

```c
void No_MCU_Ganv_Sensor_Init_Frist(No_MCU_Sensor *sensor);
```

| 参数 | 说明 |
|------|------|
| `sensor` | 传感器对象指针 |

### 2. No_MCU_Ganv_Sensor_Init()

**功能**：完整初始化传感器。计算黑白动态阈值（滞回区间）、归一化比例系数、ADC 满量程。

```c
void No_MCU_Ganv_Sensor_Init(
    No_MCU_Sensor *sensor,
    unsigned short *Calibrated_white,  // 白色标定值数组（8 元素）
    unsigned short *Calibrated_black   // 黑色标定值数组（8 元素）
);
```

**内部逻辑**：
- 每个探头的判白阈值 = (白 × 2 + 黑) / 3（靠近白色 1/3 处）
- 每个探头的判黑阈值 = (白 + 黑 × 2) / 3（靠近黑色 1/3 处）
- 归一化系数 = 4096.0 / (白 - 黑)，将差值拉伸到满量程

### 3. No_Mcu_Ganv_Sensor_Task_Without_tick()

**功能**：传感器数据采集核心任务。依次完成模拟量采集 → 数字量转换 → 归一化处理。应在主循环中每 10ms 调用一次。

```c
void No_Mcu_Ganv_Sensor_Task_Without_tick(No_MCU_Sensor *sensor);
```

| 参数 | 说明 |
|------|------|
| `sensor` | 传感器对象指针 |

**内部流程**：
1. `Get_Analog_value()`：通过多路复用器轮流采集 8 通道，每通道采样 8 次取平均
2. `convertAnalogToDigital()`：与滞回阈值比较，产生 8 位数字量
3. `normalizeAnalogValues()`：将原始值映射到 0~4096 范围

### 4. Get_Digtal_For_User()

**功能**：获取 8 位数字量结果（每 bit 代表一个探头，1=白色，0=黑色）。

```c
unsigned char Get_Digtal_For_User(No_MCU_Sensor *sensor);
```

| 参数 | 说明 |
|------|------|
| `sensor` | 传感器对象指针 |
| **返回值** | 8 位数字量，bit0=探头1, ..., bit7=探头8 |

### 5. Get_Normalize_For_User()

**功能**：获取 8 通道归一化数组。

```c
unsigned char Get_Normalize_For_User(No_MCU_Sensor *sensor, unsigned short *result);
```

| 参数 | 说明 |
|------|------|
| `sensor` | 传感器对象指针 |
| `result` | [输出] 8 通道归一化值数组 |
| **返回值** | 1=成功，0=传感器未就绪 |

### 6. Get_Anolog_Value()

**功能**：获取 8 通道原始模拟量数组。

```c
unsigned char Get_Anolog_Value(No_MCU_Sensor *sensor, unsigned short *result);
```

| 参数 | 说明 |
|------|------|
| `sensor` | 传感器对象指针 |
| `result` | [输出] 8 通道原始 ADC 值 |
| **返回值** | 1=成功，0=传感器未就绪 |

### 7. CalculateNormalizedValue() ★核心函数

**功能**：计算加权质心偏差值，用于 PID 循迹控制。返回浮点数，正值表示黑线偏右，负值表示偏左。

```c
float CalculateNormalizedValue(No_MCU_Sensor *sensor, uint8_t field);
```

| 参数 | 说明 |
|------|------|
| `sensor` | 传感器对象指针 |
| `field` | 场地类型：0=白底黑线（默认），1=黑底白线 |
| **返回值** | 加权偏差值（偏离中心越大绝对值越大） |

**算法细节**：
- 探头权重（从左到右）：-7, -5, -3, -1, 1, 3, 5, 7
- 底噪阈值：满量程的 1/3（约 1365）
- 信号强度 = 归一化值 - 底噪阈值（抑制底噪）
- 偏差 = Σ(权重 × 信号强度) / Σ(信号强度)
- 放大系数：1024（左移 10 位）提高精度
- 带脱线保持：完全看不到线时返回上一次结果

### 8. CalculateDigitalWeightedValue()

**功能**：数字量版加权偏差计算（简化版，用于脱线记忆和路口检测）。

```c
int32_t CalculateDigitalWeightedValue(unsigned char Digital, uint8_t field);
```

| 参数 | 说明 |
|------|------|
| `Digital` | 8 位数字量 |
| `field` | 场地类型：0=白底黑线，1=黑底白线 |
| **返回值** | 加权偏差值（×1024 放大） |

## 调用关系

```
main() while(1) 每 10ms:
  → No_Mcu_Ganv_Sensor_Task_Without_tick(&g_GraySensor)
    → Get_Analog_value()          // 8 通道 ADC 采样
    → convertAnalogToDigital()    // 滞回阈值判定
    → normalizeAnalogValues()     // 归一化

循迹PID:
  → CalculateNormalizedValue(&g_GraySensor, 0)  // 获取质心偏差
  → PID_Calc(&pidLine, line_offset)             // PID 计算转向量

路口检测:
  → Get_Digtal_For_User(&g_GraySensor)          // 获取数字量
  → DetectIntersectionType(digital)             // 路口类型判定
```
