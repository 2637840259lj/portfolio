# 调试模块（App Debug）

## 概述

调试模式核心模块，提供 4 种编码器/位置闭环验证测试。

## 4 种测试模式

| 模式 | 名称 | 功能 | 速度 |
|------|------|------|------|
| 0 | 100cm 30 | 100cm | 30cm/s |
| 1 | 100cm 35 | 100cm | 35cm/s |
| 2 | 100cm 40 | 100cm | 40cm/s |
| 3 | Pos Hold | PD 位置保持 | — |

三个距离模式都是 100cm、速度不同，方便快速切换对比。按 Key2 启动跑完，串口打印误差和时间。比较三种速度下位置闭环的表现。

### 模式 3：PD 位置保持

锁定当前位置，手推车看反向力矩。启用时 ISR 自动旁路速度 PID，由 PD 直接输出 PWM。

## 控制策略

位置 + 速度串级闭环：

```
编码器 → 增量式位置PID (Kp=0.03) → 速度目标 (cm/s)
       → 梯形减速剖面 (DECEL_DIST=2000脉冲) 取min
       → 速度PID ISR → PWM → 电机
```

- 软启动：速度从 5cm/s 爬升
- 巡航段：位置 PID 输出 ~巡航速度
- 减速段：最后 2000 脉冲线性降速到 5cm/s
- 到位刹车

## 可调参数

```c
#define DEBUG_SPEED_50CM      20.0f   // 50cm 巡航速度
#define DEBUG_SPEED_100CM     25.0f   // 100cm 巡航速度
#define DEBUG_POS_KP          0.03f   // 位置 PID P
#define DEBUG_DECEL_DIST      2000    // 减速距离
#define DEBUG_END_SPEED       5.0f    // 到位最低速度

#define DEBUG_HOLD_KP         1.5f    // 位置保持 P
#define DEBUG_HOLD_KD         0.3f    // 位置保持 D
#define DEBUG_HOLD_DEADBAND   3       // 死区
#define DEBUG_HOLD_MAX        800     // PWM 限幅
```

## 串口输出格式

距离测试（每秒一行）：
```
[1087ms] tgt=7130 cur=1420 rem=5710 spd=18.2 L=18.0 R=18.3
```

位置保持（每秒一行）：
```
[HOLD] errL=+12 errR=-8 pwm=150,-120
```

完成报告：
```
=== DONE! tgt=7130 act=7136 err=6 time=3250ms ===
```

## API

```c
void        Debug_Init(void);
void        Debug_SelectPrev/Next(void);   // Key1/Key3
void        Debug_Start/Stop(void);        // Key2
void        Debug_Task(void);              // 主循环调用
DebugMode_e Debug_GetMode(void);
const char* Debug_GetModeName(void);
bool        Debug_IsRunning(void);
```
