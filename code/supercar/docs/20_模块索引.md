# 模块索引

本项目的用户代码分为四层架构，从底层到上层依次为：**驱动层 → 板级支持包 → 中间件 → 应用层**。

## 依赖关系

```
应用层 (UserApp)
├── empty.c              ★ 主程序
├── app_template.c       ★ 你的业务逻辑 (在此实现)
├── app_key.c            按键交互
├── app_indicator.c      LED/蜂鸣器指示器
├── app_imu.c            IMU 数据采集 + 姿态融合
├── app_position_hold.c  电机 PD 位置保持
│
中间件 (UserMiddlewares)
├── pid.c                PID 控制器 (增量式/位置式)
├── MahonyAHRS.c         Mahony 姿态解算
├── ebtn.c               按键消抖库
│
板级支持包 (UserBsp)
├── isr.c                中断服务 (TIMA0 速度环 + 编码器)
├── sys_time.c           SysTick 系统时钟
├── bsp_adc.c            ADC 驱动
├── bsp_uart.c           UART printf 重定向
│
驱动层 (UserDrivers)
├── at4950.c             电机驱动 (PWM)
├── buzzer.c             蜂鸣器
├── encoder_driver.c     编码器 (正交解码)
├── led.c                RGB LED
├── No_Mcu_Ganv_Grayscale_Sensor.c  8路灰度传感器
├── mpu6050.c            MPU6050 IMU (I2C)
└── BMI088/              (未使用, 可删除)
```

## 模块速查表

| 模块 | 文件 | 用途 | 关键 API |
|------|------|------|----------|
| 主程序 | empty.c | 硬件初始化 + 主循环 | `main()` |
| **应用模板** | **app_template.c/h** | **你的业务逻辑入口** | `AppTemplate_Init()`, `AppTemplate_Task()` |
| 按键 | app_key.c/h | 3 按键消抖 | `APP_Key_Init()`, `APP_Key_Task()` |
| 指示器 | app_indicator.c/h | LED/蜂鸣器灯光音效 | `App_Indicator_*()` |
| IMU | app_imu.c/h | MPU6050 + 姿态融合 | `ImuApp_Init()`, `ImuApp_Update()` |
| 位置保持 | app_position_hold.c/h | 电机 PD 锁止 | `PosHold_Init/Enable/Update/Disable()` |
| PID | pid.c/h | PID 控制器 | `PID_Init()`, `PID_SetTarget()`, `PID_Calc()` |
| Mahony | MahonyAHRS.c/h | 姿态解算 | `MahonyAHRSupdateIMU()` |
| 按键库 | ebtn.c/h | 按键消抖/长按/双击 | `ebtn_init/register/process()` |
| ISR | isr.c/h | 速度 PID + 编码器中断 | (无用户 API) |
| 系统时钟 | sys_time.c/h | SysTick 1ms | `mspm0_get_clock_ms()`, `mspm0_delay_ms()` |
| ADC | bsp_adc.c/h | ADC 采样 | `bsp_adc_init()`, `adc_getValue()` |
| UART | bsp_uart.c/h | printf 重定向 | (自动使用) |
| 电机 | at4950.c/h | PWM 电机驱动 | `Motor_ConfigInit/SetSpeed/Brake()` |
| 蜂鸣器 | buzzer.c/h | 蜂鸣器 | `buzzer_init/on/off()` |
| 编码器 | encoder_driver.c/h | 正交解码 | `Encoder_Driver_Init()`, `Encoder_GetSpeedLine()` |
| LED | led.c/h | RGB LED | `led_init/on/off/toggle()` |
| 灰度 | No_Mcu_Ganv_Grayscale_Sensor.c/h | 8 路灰度 | `No_MCU_Ganv_Sensor_Init/Task_Without_tick()` |
| MPU6050 | mpu6050.c/h | I2C IMU 驱动 | `MPU_Init()`, `MPU_Get_Gyroscope()` |
