# PD 位置保持模块（Position Hold）

## 概述

独立 PD 位置锁定模块，零外部依赖。启用时锁定当前位置，外力推车时自动产生反向 PWM 抵消扰动。

## 控制律

```
err  = target_pos - current_pos       // 位置误差 (编码器脉冲)
dErr = err - last_err                 // 误差变化率
PWM  = Kp × err + Kd × dErr          // PD 输出
     = 0            (|err| ≤ deadband) // 死区: 误差太小不动作
     = clamp(±max)                    // PWM 限幅
```

- 无积分 I 项，避免积分饱和
- 死区防止静止时 PWM 微振
- 独立实现，不依赖 pid.c

## 结构体

```c
typedef struct {
    bool     enabled;         // 是否启用
    int32_t  target_pos;      // 锁定位置 (编码器脉冲)
    int32_t  last_error;      // 上周期误差 (D 项用)
    float    kp;              // P 系数 (脉冲→PWM)
    float    kd;              // D 系数
    int16_t  deadband;        // 死区 (脉冲)
    int16_t  max_output;      // PWM 限幅
} PosHold_t;
```

## API

```c
// 初始化: Kp=1.5, Kd=0.3, deadband=3, max=800
void PosHold_Init(PosHold_t *hold, float kp, float kd,
                  int16_t deadband, int16_t max_output);

// 启用: 以当前编码器值为目标
void PosHold_Enable(PosHold_t *hold, int32_t current_pos);

// 关闭
void PosHold_Disable(PosHold_t *hold);

// 每周期更新: 返回 PWM (-max ~ +max)
int16_t PosHold_Update(PosHold_t *hold, int32_t current_pos);

// 查询状态
bool PosHold_IsEnabled(const PosHold_t *hold);
```

## 使用示例

```c
#include "app_position_hold.h"

PosHold_t holdLeft, holdRight;

// 初始化
PosHold_Init(&holdLeft,  1.5f, 0.3f, 3, 800);
PosHold_Init(&holdRight, 1.5f, 0.3f, 3, 800);

// 按键锁定
PosHold_Enable(&holdLeft,  encoderLeft.total_count);
PosHold_Enable(&holdRight, encoderRight.total_count);

// 主循环 (需配合 ISR 旁路)
while (hold_enabled) {
    int16_t pwm_l = PosHold_Update(&holdLeft, encoderLeft.total_count);
    int16_t pwm_r = PosHold_Update(&holdRight, encoderRight.total_count);
    Motor_SetSpeed(&motorLeft,  pwm_l);
    Motor_SetSpeed(&motorRight, pwm_r);
}

// 释放
PosHold_Disable(&holdLeft);
PosHold_Disable(&holdRight);
```

## ISR 配合

位置保持模式下 PWM 由主循环直接设定，ISR 中的速度 PID 需旁路：

```c
// isr.c
extern bool g_poshold_active;

void TIMA0_IRQHandler(void) {
    Encoder_Update(&encoderLeft);   // 编码器更新照常
    Encoder_Update(&encoderRight);

    if (g_poshold_active) return;   // 跳过速度 PID

    // ... 正常速度 PID ...
}
```

## 参数建议

| 参数 | 起步值 | 调大 | 调小 |
|------|--------|------|------|
| kp | 1.5 | 反向力更大，可能震荡 | 更柔和 |
| kd | 0.3 | 抑制震荡，"粘性"更强 | 响应更快，可能抖 |
| deadband | 3 | 不敏感，停止时有间隙 | 非常敏感，可能微振 |
| max_output | 800 | 最大纠偏力更大 | 限幅更小 |

## 实测结果

调试模式 5 中验证：
- 左轮 1 圈误差 1 脉冲 (0.07%)
- 右轮 1 圈误差 1 脉冲 (0.07%)
- 50cm 基本准确
- 100cm 调整 DECEL_DIST 后偏差可忽略
