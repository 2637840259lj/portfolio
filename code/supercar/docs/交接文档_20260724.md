## 本次修复/改动（全部在 3507test 工程）

### 1. IMU 校准值硬编码 ✅
文件：`UserCode\UserDrivers\MPU6050\mpu6050.c` 第 9-10 行
```c
int32_t s_gyroBias[3] = {0,1,30};
int32_t s_accelBias[3] = {740,270,-184};
```
- 用 Key2 长按 60 秒校准后的值，开机直接使用，不再漂移
- Roll/Pitch 静止波动 ±0.1°，Yaw 漂移约 7°/分（无磁力计正常）

### 2. 未解决的隐患：SWD 冲突 ⚠️
文件：`E:\3507test\2025e_car\empty.syscfg` 第 213-214 行
```
UART1.peripheral.rxPin.$assign = "PA11";   ← SWCLK!
UART1.peripheral.txPin.$assign = "PA10";   ← SWDIO!
```
- **如果 syscfg 重新生成**，UART_0 会配置 PA10/PA11 为串口，JLink 就连不上了
- **当前没触发**是因为 syscfg 暂未重新运行，`ti_msp_dl_config.c` 是旧版本
- **建议修复**：删除 UART1 (UART_0) 实例，printf 已走 UART_1 (PA8/PA9)
- 对比参考：`E:\Ti3507Data\2025e_car\empty.syscfg` 已经修过了

### 3. IMU 驱动切换：BMI088 → MPU6050
- MPU6050 在 **I2C0（PA0=SDA, PA1=SCL）**，地址 0x68
- `UserCode\UserDrivers\MPU6050\mpu6050.c`：I2C 驱动，含 SDA 解锁 + 零偏校准
- `UserCode\UserApp\app_imu.c`：`ImuApp_Init()` / `ImuApp_Update()` / `ImuApp_CalibrateGyro()`
- MahonyAHRS 姿态融合，Roll/Pitch 用 `Mahony_computeAngles()`，Yaw 用角速度积分

### 4. 按键映射
| 按键 | 引脚 | 短按 | 长按 |
|---|---|---|---|
| Key1 | PB0 | 设圈数 (1→10→1) | **2s: 灰度白校准**（main 循环直接读 GPIO） |
| Key2 | PB21 | 启动任务 | **1s: IMU 零偏校准**（`ImuApp_CalibrateGyro()`，已被硬编码替代） |
| Key3 | PB23 | 停止任务 | 急停 |

### 5. 灰度白校准
- `empty.c` 第 158 行 `GrayCalibrateWhite()`
- 触发：**空闲时** Key1 按住 2 秒，绿灯常亮 → 闪烁采样 1s → 灭 + 哔 2 声
- 白值数组：`white[8]`，黑值：`black[8]`，都在 `empty.c` 第 60-61 行

### 6. printf / 串口
- printf 走 UART_1 (PA8=TX, PA9=RX, 115200)
- `bsp_uart.c` 第 27 行 `fputc` 使用 `UART_1_INST`

## 架构速查
- MCU: MSPM0G3507, 80MHz, Keil MDK + SysConfig
- 速度 PID → TIMA0 10ms ISR；主循环 10ms 只设目标值
- 转弯：编码器差速（run_mode=3），不依赖陀螺仪
- 循迹：8 路灰度 CD4051 多路复用，丢线即时刹车
- 编码器：13 线 × 4 倍频 × 28:1 减速比，车轮 Ø6.5cm
