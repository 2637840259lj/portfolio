# 指示器模块（App Indicator）

## 概述

本模块管理小车底盘的状态指示，包括 **RGB LED 状态显示** 和 **蜂鸣器异步鸣叫控制**。所有操作均采用非阻塞异步方式，不干扰主循环和 PID 控制的实时性。

## 依赖模块

| 模块 | 用途 |
|------|------|
| `led.h` | LED 开关控制 |
| `buzzer.h` | 蜂鸣器开关控制 |
| `sys_time.h` | 系统时钟基准 |

## 状态变量

```c
static bool s_mission_running = false;      // 任务运行标志
static bool s_red_blink_enable = false;     // 红灯闪烁使能
static uint8_t s_remaining_beeps = 0U;      // 剩余鸣叫次数
static bool s_buzzer_is_on = false;          // 蜂鸣器当前状态
static bool s_buzzer_wait_gap = false;       // 蜂鸣间隙等待
static uint32_t s_buzzer_tick_ms = 0U;       // 蜂鸣定时基准
```

## 显示逻辑

### LED 指示

| 状态 | 红色 LED | 绿色 LED | 条件 |
|------|----------|----------|------|
| 停车 | 亮 | 灭 | `!s_mission_running` |
| 运行中 | 灭 | 亮 | `s_mission_running` |
| 闪烁（故障/校准中） | 250ms 闪烁 | 灭 | `s_red_blink_enable` |

### 蜂鸣器控制

- 鸣叫周期：100ms ON + 100ms OFF
- 支持 N 次连续鸣叫和单次鸣叫
- 异步执行，不阻塞主循环

## API 函数详解

### 1. App_IndicatorTask()

**功能**：指示器主任务，需在 `main()` while(1) 中每 50ms 调用一次。负责 LED 状态刷新和蜂鸣器异步控制。

```c
void App_IndicatorTask(void);
```

**内部流程**：
1. 处理蜂鸣请求（N 次鸣叫 / 单次鸣叫）
2. 控制蜂鸣器 ON/OFF 时序（100ms ON + 100ms OFF 交替）
3. 每 50ms 更新一次 LED 状态
4. 红灯闪烁模式独立处理（250ms 周期）

### 2. App_Indicator_RequestBeepOnce()

**功能**：请求蜂鸣器鸣叫一次（100ms）。

```c
void App_Indicator_RequestBeepOnce(void);
```

### 3. App_Indicator_RequestBeepCount()

**功能**：请求蜂鸣器鸣叫指定次数。

```c
void App_Indicator_RequestBeepCount(uint8_t count);
```

| 参数 | 说明 |
|------|------|
| `count` | 鸣叫次数（1~255） |

> 典型用法：按键设定圈数时，蜂鸣器鸣叫 N 次对应 N 圈。

### 4. App_Indicator_SetMissionRunning()

**功能**：设置任务运行状态指示灯。

```c
void App_Indicator_SetMissionRunning(bool is_running);
```

| 参数 | 说明 |
|------|------|
| `is_running` | true=运行中（绿灯），false=停止（红灯） |

### 5. App_Indicator_SetRedBlink()

**功能**：设置红灯闪烁模式。

```c
void App_Indicator_SetRedBlink(bool enable);
```

| 参数 | 说明 |
|------|------|
| `enable` | true=使能闪烁，false=关闭闪烁并熄灭红灯 |

## 引用关系

```
main() while(1)
  → App_IndicatorTask()                     // 50ms LED + 蜂鸣器刷新

按键事件 (app_key.c)
  → LineFollow_SetTargetLaps(n)
    → App_Indicator_RequestBeepCount(n)     // 圈数蜂鸣确认

底盘控制 (car.c)
  → Car_MissionStart()
    → App_Indicator_SetMissionRunning(true) // 绿灯亮
  → Car_MissionStop()
    → App_Indicator_SetMissionRunning(false) // 红灯亮
```
