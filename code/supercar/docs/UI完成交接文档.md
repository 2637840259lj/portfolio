## 1. 本次交接结论

App 已从原有的深色赛博朋克基础样式，统一升级为 **保留赛博紫/青色语义的 Apple 式深色新拟态界面**。

核心原则：

1. **统一底色与表面层级**：使用深紫黑背景、抬升卡片、凹陷交互槽，形成可辨识的高低差。
2. **保留安全色语义**：紫色表示主操作/选中；青色表示数据与连接；绿色表示正常或前进；黄色表示警示；红色表示停止、离线异常与急停。
3. **安全优先于拟态**：急停、刹车、离线、告警不使用低对比阴影表达，仍保持清晰的色块、边线、文字与图标对比。
4. **动效克制且不参与业务**：动画仅用于按压、状态色、位置和空状态反馈；没有改变蓝牙、控制命令、轮询或页面生命周期。

## 2. 当前 UI 风格说明

### 2.1 风格定位：Neo-Apple Control

这是面向移动端小车调试/遥控场景的深色控制台风格：

- **底色**：深紫黑 `#0F0F23`，降低背景噪声，突出操作与实时数据。
- **抬升表面**：卡片使用偏紫蓝的 `raisedSurface`，结合左上微高光与右下深阴影，表达“浮起”的新拟态层级。
- **凹陷表面**：滑条槽、数据小格、摇杆轨道、RSSI/TX 指示等使用 `insetSurface` / `insetDeep` 与内阴影，表达“嵌入”的交互容器。
- **Apple 式信息层级**：圆角更统一、留白更充分、标题与辅助信息层级更清晰；弱化无意义的扫描线和装饰性霓虹。
- **保留赛博语义**：主紫、数据青、成功绿、警示黄、危险红继续用于状态识别与操作反馈。

### 2.2 表面与圆角规范

| 层级 | 使用场景 | 视觉处理 |
|---|---|---|
| 基础背景 | 页面底色、AppBar 背景 | `background` 深色底，避免抢占信息注意力 |
| 抬升卡片 | 状态卡、功能卡、工具栏、弹层、设备卡 | `raisedSurface` + `raisedShadows` 或 `raisedShadowsStrong` |
| 凹陷槽/格 | 速度滑条、实时小读数、摇杆轨道、灰度未激活格 | `insetSurface` / `insetDeep` + `insetShadows` |
| 强调操作 | 前进、倒车、刹车、急停、激活 Tab | 渐变填充 + 高光描边 + 语义色辉光 |

圆角 token：

- 控件：`radiusControl = 12`
- 卡片：`radiusCard = 16`
- 面板/导航胶囊：`radiusSheet = 20`

间距 token：4 / 8 / 12 / 16 / 24，对应 `space1` 至 `space5`。

### 2.3 颜色语义

| 语义 | 主色 | 用途 |
|---|---|---|
| 主操作 / 当前选中 | 紫色 `#7C3AED` | Tab、主操作、示教占位语义 |
| 数据 / 在线连接 | 青色 `#22D3EE` | 硬件数据、连接信息、摇杆方向 |
| 正常 / 前进 / 成功 | 绿色 `#10B981` / `#4ADE80` | 前进、在线、正常状态 |
| 警示 | 黄色 `#F59E0B` | 安全提示、注意事项 |
| 危险 / 停止 / 离线 | 红色 `#EF4444` | 刹车、急停、离线与异常 |
| 主文字 / 辅助文字 | `#E2E8F0` / `#94A3B8` | 标题/实时数值与说明文字 |

> 后续新增控件时，不要用颜色替代文字或图标；危险和连接状态必须同时保留色彩、文字与图标/边线提示。

## 3. 已完成页面与组件

### 3.1 遥控页 `app/lib/pages/control_page.dart`

- 左右实时状态参数栏改为强抬升卡，在线数据采用青色边线；离线/异常保留红色边线与辉光。
- 参数行改为凹陷小格，实时数值与标签分层更清晰。
- 速度区改为大圆角抬升卡，滑条置于深凹陷槽内。
- 前进、倒车、刹车采用更明显的渐变填充、高光描边、阴影与语义辉光：
  - 前进：绿色；
  - 倒车：紫色；
  - 刹车：红色高对比，始终优先可见。
- 背景扫描线透明度已降低，避免干扰控制读取。

### 3.2 方向摇杆 `app/lib/widgets/joystick.dart`

- 摇杆增加独立抬升底座与“方向控制”标题。
- 轨道采用深凹陷处理；摇杆帽采用渐变、白色高光描边和高光点，拖动状态更直观。
- 松手时维持既有视觉 spring 回中；控制回调、50ms 发送节奏、拖动边界与松手行为未修改。

### 3.3 急停 `app/lib/widgets/emergency_fab.dart`

- 急停采用红色渐变、白色边框和三层阴影（语义辉光、深阴影、高光）。
- 禁用态保留弱抬升，避免控件“消失”。
- 未加入拖动惯性，防止安全按钮松手后继续移动。

### 3.4 扫描页与主导航 `app/lib/pages/scan_page.dart`

- AppBar 与页面底色统一。
- 扫描/连接状态条升级为带边线与阴影的抬升状态卡，并保留平滑状态切换。
- 蓝牙设备列表升级为抬升卡；CH9141 目标设备继续以语义色突出。
- 空状态升级为抬升卡 + 凹陷图标容器。
- 主导航侧栏升级为浮动胶囊面板：
  - 当前 Tab 使用紫色渐变实心、白色描边与辉光；
  - 未选中 Tab 保持低干扰，但仍清晰可点。
- 顶部 RSSI 与 TX 指示升级为凹陷小格。

### 3.5 电机页 `app/lib/pages/param_page.dart`

- 页面卡片、页头、安全提示统一使用抬升卡层级。
- 左右轮速度仪表使用凹陷数据格。
- 电机点动按钮的激活态采用渐变、高光描边与辉光。
- 点动、保活、停止、自动整定等业务行为未改动。

### 3.6 IMU 页 `app/lib/pages/telem_page.dart`

- 工具栏、校准卡、图表卡、引导卡统一为抬升卡。

- 高频遥测数据未强行做逐数值动画，避免刷新抖动和额外渲染负担。

### 3.7 循迹页 `app/lib/pages/line_page.dart`

## 4. 通用动效与交互反馈

主题中已统一以下纯 UI token：

- 曲线：`easeOut`、`easeInOut`
- 时长：按压 120ms、快速状态 150ms、标准过渡 200ms
- 通用组件：`app/lib/widgets/press_scale.dart`

已覆盖的反馈：

- 按钮按压缩放；
- Tab 选中态切换；
- 状态卡/状态条边线与文字颜色切换；
- 灰度阵列状态切换与循迹 marker 位移；
- 摇杆视觉 spring 回中；
- IMU 空状态、示教占位页的轻量入场。

动效原则：操作触发应立即生效，动效不能延迟停车、刹车、急停、蓝牙命令或页面清理。

## 7. 后续开发规范

1. 新增页面优先复用 `CyberpunkTheme` 的表面、圆角、间距、阴影与动效 token，不要再次散落硬编码阴影或圆角值。
2. 普通信息容器用抬升卡；需要承载连续交互或实时读数的局部区域用凹陷槽/格。
3. 只有当前选中、激活、危险或需要即时识别的对象可以使用渐变、辉光和高对比描边；不要让所有控件都发光。
4. 危险操作必须保留红色、高对比文本/图标和清晰边界，不可仅依赖新拟态阴影。
5. 高频数据（遥测、扫描结果、轮速）不要增加重复入场动画或逐帧数字补间，避免视觉抖动。
6. 新增交互动效必须是纯视觉效果，不能改变回调触发时机、命令发送顺序、控制周期或页面 dispose 时机。
