# 蜂鸣器驱动模块

## 概述

通用蜂鸣器驱动模块，基于 MSPM0 DriverLib 实现，支持有源蜂鸣器（高/低电平有效可配置）的开关和状态查询。本项目预定义一个蜂鸣器实例 `buzzer0`。

## 硬件引脚映射

| 功能 | 信号 | MCU 引脚 | 有效电平 |
|------|------|----------|----------|
| 蜂鸣器 | BUZZER | PA7 | 高电平有效 |

> 蜂鸣器引脚已在 SYSCFG 中配置为数字输出，初始状态为低电平（关闭）。

## 数据结构

### buzzer_gpio_t

```c
typedef struct {
    void *port;             // GPIO 端口基地址
    uint32_t pin;           // GPIO 引脚掩码
    uint8_t active_level;   // 激活电平：BUZZER_ON(1)=高有效, BUZZER_OFF(0)=低有效
} buzzer_gpio_t;
```

### buzzer_device_t

```c
typedef struct {
    buzzer_gpio_t gpio;  // GPIO 配置
    uint8_t state;        // 当前状态（BUZZER_ON 或 BUZZER_OFF）
} buzzer_device_t;
```

### 预定义蜂鸣器实例

| 变量名 | 端口 | 引脚 | 有效电平 |
|--------|------|------|----------|
| `buzzer0` | GPIOA | PA7 | 高有效 |

### 状态常量

```c
#define BUZZER_OFF  0  // 关闭
#define BUZZER_ON   1  // 启动
```

## API 函数详解

### 1. buzzer_init()

**功能**：初始化蜂鸣器。将状态重置为关闭，GPIO 配置已由 SYSCFG 处理。

```c
void buzzer_init(buzzer_device_t *buzzer);
```

| 参数 | 说明 |
|------|------|
| `buzzer` | 蜂鸣器设备指针 |

### 2. buzzer_on()

**功能**：启动蜂鸣器。根据 `active_level` 自动选择正确的 GPIO 电平。

```c
void buzzer_on(buzzer_device_t *buzzer);
```

| 参数 | 说明 |
|------|------|
| `buzzer` | 蜂鸣器设备指针 |

### 3. buzzer_off()

**功能**：关闭蜂鸣器。

```c
void buzzer_off(buzzer_device_t *buzzer);
```

| 参数 | 说明 |
|------|------|
| `buzzer` | 蜂鸣器设备指针 |

### 4. buzzer_get_state()

**功能**：获取当前蜂鸣器状态。

```c
uint8_t buzzer_get_state(buzzer_device_t *buzzer);
```

| 参数 | 说明 |
|------|------|
| `buzzer` | 蜂鸣器设备指针 |
| **返回值** | `BUZZER_ON`(1) 或 `BUZZER_OFF`(0) |

### 5. buzzer_set_state()

**功能**：设置蜂鸣器状态。

```c
void buzzer_set_state(buzzer_device_t *buzzer, uint8_t state);
```

| 参数 | 说明 |
|------|------|
| `buzzer` | 蜂鸣器设备指针 |
| `state` | `BUZZER_ON`(1) 或 `BUZZER_OFF`(0) |

## 引用关系

- **main() 初始化**：调用 `buzzer_init(&buzzer0)`，上电短鸣 200ms 自检。
- **app_indicator**：通过 `buzzer_on()`/`buzzer_off()` 实现异步蜂鸣控制——支持单次鸣叫（100ms ON + 100ms OFF）和 N 次鸣叫序列，不会阻塞主循环。
