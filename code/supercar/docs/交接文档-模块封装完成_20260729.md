## 三、已完成的核心改动

### 3.1 app_ins.c — 指令示教运动指令 PID 闭环改造

**涉及 6 个运动指令，全部接入 PID 闭环 + schedule 插值 + 超时/卡滞检测：**

| Opcode | 指令 | 闭环方式 |
|---|---|---|
| 0x01 | MOVE_CM | 位置闭环 + 航向保持 |
| 0x02 | MOVE_RAMP | 位置闭环 + 航向保持 |
| 0x03 | MOVE_TRANSITION | 位置闭环 + 航向保持（到点不停）|
| 0x04 | MOVE_IMU | 航向 PID + 位置减速 |
| 0x10 | ROTATE_INPLACE_IMU | 航向 PID 闭环（替代原开环定速）|
| 0x20 | LINE_FOLLOW | 循线 PID + 位置减速 |

**新增辅助函数：**
- `ins_seg_dist()` — 双轮编码器平均距离计算
- `ins_motion_error()` / `ins_motion_check()` / `ins_est_timeout()` — 超时和卡死检测
- `ins_clampf()` / `ins_relative_yaw()` / `ins_load_schedule()` / `ins_cruise_speed()`

**新增指令 opcode：** 0x21 LINE_UNTIL_LOST / 0x22 LINE_FOLLOW_TIME / 0x23 LINE_CURVE

**新增导出接口：** `AppIns_IsActive()`, `AppIns_GetAt()`（用于脚本分段导出）

### 3.4 OLED SSD1306 接入

**最终方案：硬件 I2C0 (PA0/PA1) 与 MPU6050 共享总线**

| 设备 | I2C 地址 |
|---|---|
| MPU6050 | 0x68 |
| SSD1306 OLED | 0x3C |

- 设备地址不冲突，但 OLED 全屏刷屏 (~50-92ms) 与 IMU 更新可能碰撞
- 字库大小: F6x8 + F8X16，从 keil/22 工程复用
- API: `AppOLED_Init()` / `Clear()` / `ShowString()` / `ShowNum()` / `ShowTime()` / `ShowTimeAt()`
- 请插驱动板的 OLED 接口 (CN6/CN7)，避免飞线

### 3.5 g_imu_enabled IMU 使能开关

**目的：** I2C0 总线上 MPU6050 和 OLED 共用，比赛循迹不依赖航向，关闭 IMU 更新以节省总线带宽。

| 位置 | 内容 |
|---|---|
| empty.c 全局变量区 | `bool g_imu_enabled = true;` + 20 行中文注释 |
| 10ms 控制回路 | `else if (g_imu_enabled) { ImuApp_Update(&dt); }` |
| 校准路径 | `ImuApp_IsCalibrating()` 不受此开关影响 |
| Competition_Start() | 自动 `g_imu_enabled = false` |
| Competition_Stop() / SetFailed() / FINISHED / PRIM_STOP | 自动 `g_imu_enabled = true` |

## 五、两层控制架构

```
外环 (empty.c 10ms 控制回路)
  ├── app_ins 写 g_ble_target_* → 主循环同步到 targetSpeedLeft/Right
  ├── app_competition 直接写 targetSpeedLeft/Right
  └── app_template 直接写 targetSpeedLeft/Right
         │
         ▼
内环 (isr.c TIMA0 10ms ISR)
  速度 PID (pidLeftSpeed / pidRightSpeed) → PWM
```

全局 PID 对象: `pidLeftSpeed`, `pidRightSpeed`(内环), `pidLine`, `pidAngle`, `pidPosition`(外环)

## 八、硬件接口分配

| 外设 | 接口 | 引脚 |
|---|---|---|
| MPU6050 | I2C0 | PA0 (SCL) / PA1 (SDA) |
| SSD1306 OLED | I2C0（共享） | PA0 (SCL) / PA1 (SDA)，地址 0x3C |
| CH9141 BLE | UART3 | PB12 (TX) / PB13 (RX) |
| K230 视觉 | UART1 | PA9 (TX) / PA10 (RX) |
| 左电机 | PWM0 / TIMA0 | PB4 / PB5（编码器） |
| 右电机 | PWM1 / TIMA1 | PB17 / PB18（PWM），PB10 / PB11（编码器） |
| 步进电机 | GPIO | STEP=PA10(注意与UART1 RX冲突,待确认) / DIR=PA11 / EN=PA12 |
| 启动按键 | GPIO | PB0 (KEY1) |
| LED / 蜂鸣器 | GPIO | 按原配置 |

**注意：** PA10 被 K230 UART1 RX 和步进电机 STEP 同时占用，需调整引脚分配或增加选择逻辑。
