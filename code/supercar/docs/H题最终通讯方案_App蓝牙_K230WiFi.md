# H题最终通讯方案：App 蓝牙控制 + K230 内置 WiFi 图传

> 日期：2026-07-29  
> 适用题目：2026 电赛 H 题——车载平衡滚球运动控制系统  
> 状态：最终确定，替代所有 PC 上位机与 MCU ESP-01S 控制方案。

## 1. 最终架构

```text
┌──────────────────────── 手机 App（Flutter）────────────────────────┐
│                                                                    │
│  控制 / 参数 / 遥测                         实时视频 / 录制 / 回放  │
│          │                                             │           │
│          │ BLE                                         │ WiFi       │
└──────────┼─────────────────────────────────────────────┼───────────┘
           │                                             │
     ┌─────▼─────┐                                 ┌─────▼─────┐
     │  CH9141   │                                 │ K230 内置 │
     │ 蓝牙模块  │                                 │   WiFi    │
     └─────┬─────┘                                 └─────┬─────┘
           │ UART3                                       │ 摄像头/推流
           │ PB12 TX / PB13 RX                            │
┌──────────▼──────────┐                     ┌────────────▼───────────┐
│   MSPM0G3507 MCU     │  UART2, 115200      │           K230          │
│  循线 / 电机 / 平衡  │◄───────────────────│ 球检测 / YOLO / 图传    │
│  BLE 协议 / OLED     │ PB15 TX, PB16 RX    │                         │
└─────────────────────┘   $BALL,x,y\r\n     └────────────────────────┘
```

**唯一正式方案：**

- App 与 MCU：通过 **CH9141 BLE** 通信，复用现有 Flutter BLE 协议和 MCU 蓝牙协议栈。
- App 与 K230：手机连接 **K230 自带 WiFi**，直接接收 K230 提供的 MJPEG 或 RTSP 视频流；App 负责显示、录制和回放。
- K230 与 MCU：K230 通过 **UART2** 上报球位置；此链路只服务实时平衡控制，不传输视频。
- ESP-01S、PC 上位机和 MCU 上的 AT/TCP 桥接均不再属于该方案。

## 2. 硬件接口与接线

| 链路 | 小车端 | 对端 | 参数 / 说明 |
|---|---|---|---|
| App ↔ MCU 控制 | CH9141 → MSPM0 UART3 | App 蓝牙 | UART3：PB12=TX、PB13=RX，115200、8N1；恢复原模块与原接线 |
| App ↔ K230 视频 | K230 内置 WiFi | App WiFi | 由 K230 建立 AP 或接入现场路由器；视频协议以 K230 实际输出的 MJPEG 或 RTSP 为准 |
| K230 → MCU 球坐标 | K230 TX → PB16 | MSPM0 UART2 RX | 115200、8N1，K230 每秒约 30 帧发送球坐标 |
| MCU → K230（预留） | PB15 → K230 RX | K230 | 当前可不接；仅在需要下发视觉模式、标定命令时启用 |
| 地线 | GND | GND | CH9141、K230、MSPM0 必须共地 |

> ESP-01S 不再接入 MCU 的 PB12/PB13；将 CH9141 恢复接回 UART3。

## 3. 两条通信链路的职责

### 3.1 蓝牙控制链路：App ↔ CH9141 ↔ MCU

保留已验证的二进制帧格式：

```text
[0xAA][LEN][CMD][PAYLOAD][XOR8]
```

由现有模块负责：

- App：`ble_connection.dart`、`ble_protocol.dart`、各控制/参数服务。
- MCU：`ble.c`、`ble_protocol.c`、`app_ble.c`、`app_ble_ascii.c`、`app_ble_remote.c`。

此链路承载：遥控、开始/停止、急停、循线任务、PID 参数读写、状态 ACK、遥测和调试信息。**不承载视频数据。**

### 3.2 视频链路：App ↔ K230 内置 WiFi

K230 负责摄像头采集、YOLO/球检测、视频编码及网络推流；App 只作为视频客户端：

- 实时预览：优先使用 K230 实际提供的 MJPEG over HTTP/TCP；若 K230 提供 RTSP，则按 RTSP 地址播放。
- 录制：App 将收到的视频帧或视频流保存到手机本地目录。
- 回放：App 从本地录像列表选择并播放；不需要把视频传回小车。
- 视频显示与 BLE 控制可以在同一页面并存，但两者独立重连、独立报错。

> 手机通常在连接 K230 热点后没有互联网，这是正常现象。比赛应用只需要局域网视频和 BLE 控制，不依赖外网。

## 4. App 端功能与实现范围

现有 Flutter 项目已具备 CH9141 BLE 扫描、连接、二进制协议、遥测和控制页面。需新增视频功能，但**不改动 BLE 通讯服务**。

建议新增模块：

| 建议文件 | 职责 |
|---|---|
| `lib/services/k230_video_service.dart` | 管理 K230 视频 URL、WiFi 视频连接、帧流或播放器状态、断线重连 |
| `lib/widgets/k230_video_view.dart` | 实时视频渲染组件，显示连接/缓冲/错误状态 |
| `lib/services/video_record_service.dart` | 将视频录制到 App 本地目录，维护录像元数据 |
| `lib/pages/video_replay_page.dart` | 录像列表与本地回放 |
| `lib/pages/video_page.dart` | 图传与录制主页面；可嵌入控制主页面或独立标签页 |

依赖选择须在确认 K230 输出协议后决定：

- **MJPEG/HTTP**：可用 Dart `HttpClient` 接收 JPEG 边界流，使用 `Image.memory` 显示；录制保存为连续 JPEG 或转码后视频。
- **RTSP**：优先选用支持移动端 RTSP 的 Flutter 播放器插件；实际依赖及平台配置以 K230 的最终 RTSP 地址和编码格式为准。

## 5. K230 与 MCU 球坐标协议

K230 以 UART2 向 MCU 单向上报：

```text
$BALL,<x>,<y>\r\n
```

示例：

```text
$BALL,23,-5\r\n
```

约束：

- 波特率：115200，8N1。
- 频率：目标 30 Hz。
- `x`、`y` 是有符号整数；在首次平衡调试前必须统一单位和零点：建议 MCU 控制环直接使用 **毫米**，K230 负责像素到毫米的标定换算。
- MCU 已由 `app_ball_vision.c/.h` 在 UART2 RX 中断中解析、缓存最新坐标、记录时间戳和错误计数。
- 平衡控制模块读取 `BallVision_GetPosition()`；若超时未收到新帧，应进入安全降级/停止摆杆输出。

## 6. 启动、连接与联调顺序

1. **恢复硬件**：ESP-01S 从 MCU UART3 拔除；CH9141 接回 PB12/PB13；所有模块共地。
2. **烧录 MCU 蓝牙版固件**：使用本次恢复后生成的固件；上电后不应再配置 `CarCtrl` 或发送任何 AT 指令。
3. **蓝牙单测**：App 扫描到 `CH9141BLE2U`，连接后执行 PING、参数读取、遥测与急停测试。
4. **K230 视频单测**：让 K230 只启动摄像头与内置 WiFi 推流；手机连接 K230 网络，用浏览器或测试播放器确认视频 URL 可打开。
5. **App 视频单测**：实现并验证实时预览、开始/停止录制、保存录像、离线回放。
6. **K230 → MCU 串口单测**：先固定发送 `$BALL,0,0\r\n`；确认 MCU 有效帧计数连续增长，再测试正负坐标。
7. **联合测试**：同时打开蓝牙控制与 K230 视频，验证视频断开不会影响小车紧急停止和闭环控制；BLE 断开也不得影响 K230 向 MCU 的球位置上报。
