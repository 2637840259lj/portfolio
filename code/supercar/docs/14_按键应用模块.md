# 按键应用模块（App Key）

## 概述

基于 ebtn 库的按键管理，三键去抖 + 事件分发。**支持双模式**：通过 `DEBUG_KEY_MODE` 宏切换调试/竞赛按键映射。

## 硬件引脚

| 按键 | MCU 引脚 | 有效电平 |
|------|----------|----------|
| Key1 | PB0 | 低电平有效 |
| Key2 | PB21 | 低电平有效 |
| Key3 | PB23 | 低电平有效 |

## 双模式切换

```c
// app_key.c 第 15 行
#define DEBUG_KEY_MODE 1   // 1=调试模式, 0=竞赛模式
```

## 调试模式按键（DEBUG_KEY_MODE = 1）

| 按键 | 短按 | 长按 |
|------|------|------|
| Key1 (PB0) | 上一测试模式 | 2s: 灰度白校准（empty.c GPIO 检测） |
| Key2 (PB21) | 启动 / 停止测试 | 急停 |
| Key3 (PB23) | 下一测试模式 | — |

## 竞赛模式按键（DEBUG_KEY_MODE = 0）

| 按键 | 短按 | 长按 |
|------|------|------|
| Key1 (PB0) | 上一任务 | — |
| Key2 (PB21) | 启动 / 急停 | 急停 |
| Key2 释放 | 计时开始 | — |
| Key3 (PB23) | 下一任务 | — |

## ebtn 配置参数

```c
static const ebtn_btn_param_t defaul_ebtn_param = EBTN_PARAMS_INIT(
    20,     // 按下消抖 20ms
    20,     // 释放消抖 20ms
    50,     // 最短单击 50ms
    500,    // 最长单击 500ms (超过算长按)
    450,    // 多次单击间隔 450ms
    1000,   // 长按触发周期 1000ms
    5       // 最大 5 连击
);
```

## 事件处理逻辑

### 调试模式

| 事件 | Key1 | Key2 | Key3 |
|------|------|------|------|
| ONCLICK | `Debug_SelectPrev()` | `Debug_Start()` / `Debug_Stop()` | `Debug_SelectNext()` |
| KEEPALIVE | — | 急停 `Debug_Stop()` | — |

### 竞赛模式

| 事件 | Key1 | Key2 | Key3 |
|------|------|------|------|
| ONCLICK | `Competition_PrevTask()` | `Competition_Start()` / `Competition_Stop()` | `Competition_NextTask()` |
| ONRELEASE | — | `Competition_NotifyConfirmReleased()` | — |
| KEEPALIVE | — | 急停 `Competition_Stop()` | — |

## API

```c
int  APP_Key_Init(void);    // 初始化 ebtn
void APP_Key_Task(void);    // 主循环调用: ebtn_process()
```

## 调试输出

`DEBUG_ENABLE = 1` 时串口打印按键事件，比赛时改为 0。
