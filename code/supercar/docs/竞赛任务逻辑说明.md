# 2024 电赛 H 题《自动行驶小车》任务逻辑（当前实测版）

## 赛道布局

```
               100cm
          A ●←──────────→● B
           /              \
          /   左弧线        \   右弧线
         /    (R=40cm)      \   (R=40cm)
        D ●                  ● C
               ←220cm→
```

- **A↔B、C↔D 之间没有黑线**，用 IMU 航向直行
- **左弧线 A↔D**、**右弧线 B↔C** 有黑线，灰度循线
- 车只能前进，不能后退

## 按键与 LED

| 按键 | 引脚 | 短按 | 长按 |
|------|------|------|------|
| Key1 | PB0 | 上一任务 | 2s: 灰度白校准 |
| Key2 | PB21 | 启动 / 急停 | 急停 |
| Key3 | PB23 | 下一任务 | — |

| 任务 | 空闲灯 | 运行灯 |
|------|--------|--------|
| 1 | 🔴 红 | 🟢 绿 |
| 2 | 🟢 绿 | 🟢 绿 |
| 3 | 🔵 蓝 | 🟢 绿 |
| 4 | 🟣 红+蓝 | 🟢 绿 |

任务完成后可切换（IDLE/FINISHED/FAILED 都行）。失败 = 红灯闪 + 3 声。途经点 = 短滴。完成 = 长鸣。

## 任务 1 — A→B IMU 直行 ~2s

```
Phase 0: IMU 航向直行 100cm (7130)  35cm/s
  ↓ 走满距离 ≥500ms
Phase 1: 刹车 + 长鸣
```

车放 A 朝 B，按 K2。不检测丢线。

---

## 任务 2 — A→B→C→D→A 闭环 ~14s

```
Phase 0: A→B     IMU 直行        7130   30cm/s  航向0°
Phase 1: B→C     右弧线循线      8960   25cm/s  出线右偏20°惯性满距
Phase 2: C→D     IMU 直行        7130   30cm/s  航向0°
Phase 3: D→A     左弧线循线      8960   25cm/s  出线右偏20°惯性满距
Phase 4: 刹车 + 长鸣
```

弧线末尾 70%+ 出线 → 不失败，用 IMU 偏航直行惯性走满距离再切换。

---

## 任务 3 — A→C→B→D→A 对角 ~15s

```
Phase 0: A→C  对角IMU   6846  30cm/s  偏左45°直行 → 右转45°弧线 → 扫线切
Phase 1: C→B  右弧线   10217  30cm/s  出线偏右20°惯性满距
Phase 2: B→D  对角IMU   7273  30cm/s  偏右60°直行 → 左转45°弧线 → 扫线切
Phase 3: D→A  左弧线    8576  30cm/s  出线偏左20°惯性满距 → 停车长鸣
```

对角段：偏航 + 弯中弧线转向 + 扫黑线到位。拐后限速 25cm/s。

---

## 任务 4 — 任务3 路线 ×4 圈 ~61s

```
for lap = 0~3:
  Phase 0: A→C  对角IMU   6186  40cm/s  偏左50° → 右转50°弧线
  Phase 1: C→B  右弧线   10217  28cm/s  出线偏右20°
  Phase 2: B→D  对角IMU   7643  40cm/s  偏右50° → 左转45°弧线
  Phase 3: D→A  左弧线    8576  28cm/s  出线偏左20°
  lap<3 → 圈数+1, 回Phase 0
  lap=3 → 停车长鸣
```

高速模式：对角 40cm/s，弧线 28cm/s。拐后扫线限速 25cm/s 防冲过。

---

## 通用保护

| 机制 | 说明 |
|------|------|
| 最小脉冲保护 | 走不够 1500 脉冲 + 不足 800ms → 不判丢线 |
| 弧线末尾 | 70%+ 距离出线 → 不失败，惯性走满距离 |
| coast 过渡 | 入 coast 前 200ms steer 平滑混合防卡顿 |
| 拐弯衔接 | 同速无缝过渡，拐后扫线限速 |
| Phase 最小时长 | 500ms |
| yaw 漂移 | 每段对角重新锁 yaw |
| 丢线超时 | 连续 150ms → FAIL |
| 计时 | 确认键释放瞬间开始 |
