# 交接文档 — MSPM0G3507 智能小车通用模板

## 项目概述

基于 TI MSPM0G3507 (Cortex-M0+, 80MHz) 的智能竞赛小车平台。  
开发环境: **Keil MDK + SysConfig** (TI SDK 2.10)。

## 快速上手

### 1. Keil 工程配置

打开 `keil/empty_LP_MSPM0G3507_nortos_keil.code-workspace`，进行以下操作后 Rebuild：

**从工程中移除以下源文件**（右键 → Remove File，不删除磁盘文件）：
- `app_competition.c`
- `app_debug.c`
- `car.c`

**添加新文件到工程**（右键 Source Group → Add Existing Files）：
- `app_template.c`

Rebuild 应该 0 错误 0 警告。

### 2. 运行

编译生成的 `.hex` 烧录到 MSPM0G3507 核心板。上电后：
- RGB LED 各闪 150ms → 自检通过
- 蓝灯 500ms + 哔 1 声 → IMU 初始化成功
- 红灯常亮 → 空闲就绪
- 串口每秒输出 `[HEARTBEAT]` 心跳数据

### 3. 开始开发

复制整个 `Enoder_car` 文件夹作为新项目 → Keil 里按第 1 步配置 → 在 `app_template.c` 的 `Init()` 和 `Task()` 里写你的代码。

所有全局变量（电机、编码器、IMU、PID）都在 `empty.c` 开头定义好了，在你的代码中直接 `extern` 引用即可：

```c
extern MOTOR_t   motorLeft, motorRight;
extern Encoder_t encoderLeft, encoderRight;
extern PID_t     pidLeftSpeed, pidRightSpeed;
extern float     targetSpeedLeft, targetSpeedRight;
extern ImuData_t g_imuData;       // yaw, roll, pitch, hw_ok
extern bool      g_poshold_active; // 设 true 可旁路 ISR 速度 PID
```

文档里有完整引脚表和参数速查，详见 `docs/20_模块索引.md`。

## 硬件配置

| 外设 | 引脚 | 说明 |
|------|------|------|
| 电机左 | PA4/PA5 (PWM0) | AT4950 H桥 |
| 电机右 | PA6/PA7 (PWM1) | AT4950 H桥 |
| 编码器左 | PB6/PB7 (GPIO中断) | 13线×4倍频, 52PPR |
| 编码器右 | PB4/PB5 (GPIO中断) | 同上 |
| IMU | PA0(SCL)/PA1(SDA) | MPU6050, I2C0, 400kHz |

| 按键2 | PB21 | 短按=打印 "Key2 CLICK" |
| 按键3 | PB23 | 短按=打印 "Key3 CLICK" |
| LED红 | PB14 | RGB LED |
| LED绿 | PB15 | RGB LED |
| LED蓝 | PB18 | RGB LED |
| 蜂鸣器 | PB20 | 有源蜂鸣器 |
| 灰度 | PA11(ADC) + PB1/2/3(CD4051) | 8路灰度, 多路复用 |
| 调试串口 | PA8(TX)/PA9(RX) | UART1, 115200, printf |

## ISR 说明

### TIMA0 10ms 中断 (isr.c)
- 读取编码器速度
- 运行速度 PID (`pidLeftSpeed` / `pidRightSpeed`)  
- 输出 PWM 到电机
- **当 `g_poshold_active = true` 时跳过速度 PID**（留给位置保持模块控制）

### GPIO 编码器中断
- 正交编码器信号边沿检测
- 自动更新 `encoderLeft.total_count` / `encoderRight.total_count`

### 速度目标
设置 `targetSpeedLeft` / `targetSpeedRight` (cm/s)，ISR 会自动通过速度 PID 闭环驱动电机。

## 可删除的文件

以下文件是之前开发留下的，新项目不需要：
- `UserCode/UserApp/app_competition.c/h` — 竞赛任务模块
- `UserCode/UserApp/app_debug.c/h` — 调试测试模块
- `UserCode/UserApp/car.c/h` — 旧版循迹代码
- `UserCode/UserDrivers/BMI088/` — 未使用的 IMU 驱动

从 Keil 工程中移除这些源文件即可，不删除也不影响编译（只要不在工程中）。

## 开发提示

### 编写一个新功能
1. 在 `app_template.c` 中添加状态机/变量
2. 通过 `targetSpeedLeft/Right` 控制车轮速度
3. 通过 `g_imuData.yaw` 获取航向角
4. 通过 `encoderLeft/Right.total_count` 获取里程
5. 通过 `PID_*()` API 创建和使用 PID 控制器

### 添加新模块
1. 在 `UserCode/UserApp/` 中创建 `your_module.c` 和 `your_module.h`
2. 在 `app_template.c` 中 `#include "your_module.h"`
3. 在 Keil 工程中添加 `your_module.c` 到 Source Group

### 调试
- 串口 115200, PA8(TX)/PA9(RX)
- 用 `printf()` 输出日志
- LED 灯辅助状态指示 (红灯=空闲, 绿灯=运行)
- 蜂鸣器辅助声音反馈
