# 中断服务程序模块（ISR）

## 概述

本模块集中管理所有硬件中断服务程序。当前启用的中断包括：
- **TIMA0**：10ms 定时器中断 → 速度 PID 闭环控制
- **GPIOB (GROUP1)**：编码器 A/B 相脉冲捕获
- **ADC0**：ADC 转换完成中断（在 `bsp_adc.c` 中定义）

## 中断向量表

| 中断源 | IRQn | 优先级 | 处理函数 | 功能 |
|--------|------|--------|----------|------|
| TIMA0 | TIMA0_INT_IRQn | 默认 | `TIMA0_IRQHandler()` | 10ms 速度环 |
| GPIOB | GPIOB_INT_IRQn | 2 | `GROUP1_IRQHandler()` | 编码器脉冲捕获 |
| ADC0 | ADC0_INT_IRQn | 0 | `ADC0_IRQHandler()` | ADC 转换完成 |
| SysTick | SysTick_IRQn | 0 | `SysTick_Handler()` | 1ms 系统时钟 |

## ISR 函数详解

### 1. TIMA0_IRQHandler() ★速度闭环核心

**功能**：每 10ms 触发一次，执行左右编码器速度计算 + PID 速度闭环。

```c
void TIMA0_IRQHandler(void);
```

**中断条件**：`DL_TIMER_IIDX_ZERO`（定时器零事件）

**执行流程**：
1. 检查 TIMA0 零事件中断标志
2. `Encoder_Update(&encoderLeft)` — 左轮速度计算（含滤波）
3. `Encoder_Update(&encoderRight)` — 右轮速度计算
4. `Encoder_GetSpeedLine()` — 获取滤波速度（cm/s）
5. `PID_Calc(&pidLeftSpeed, currentSpeedLeft)` — 左轮 PID 计算
6. `PID_Calc(&pidRightSpeed, currentSpeedRight)` — 右轮 PID 计算
7. `Motor_SetSpeed(&motorLeft, outLeft)` — 左轮 PWM 输出
8. `Motor_SetSpeed(&motorRight, outRight)` — 右轮 PWM 输出

> **关键设计**：速度闭环在中断中执行，保证 10ms 稳定周期，不受主循环扰动影响。

### 2. GROUP1_IRQHandler() ★编码器中断

**功能**：处理 GPIOB 端口上编码器（4 个引脚）的上升/下降沿中断，执行 4 倍频正交解码。

```c
void GROUP1_IRQHandler(void);
```

**中断条件**：GPIOB 端口任意使能的编码器引脚发生边沿变化

**执行流程（高度优化）**：
1. 读取使能的中断状态（仅编码器 4 个引脚）
2. 判断左编码器：读取 A/B 相电平 → 生成 2bit 状态码 → 查表 → 累加脉冲
3. 判断右编码器：同上
4. 清除中断标志

**优化细节**：
- 静态常量避免每次计算引脚掩码
- `!!(pins & PIN)` 消除分支
- 去掉了 `prev_state != 0xFF` 判断（容忍上电首脉冲 1 个误差，换取更小中断延迟）
- 合并清除中断标志（一次调用替代两次）

**编码器 4 倍频查表（Encoder_QuadTable）**：

| prev\curr | 00 | 01 | 10 | 11 |
|-----------|---|---|---|----|----|
| **00** | 0 | +1 | -1 | 0 |
| **01** | -1 | 0 | 0 | +1 |
| **10** | +1 | 0 | 0 | -1 |
| **11** | 0 | -1 | +1 | 0 |

### 3. ADC0_IRQHandler()

**功能**：ADC 转换完成中断处理。定义在 `bsp_adc.c` 中，此处列出完整性。

```c
void ADC0_IRQHandler(void);
```

**中断条件**：`DL_ADC12_IIDX_MEM3_RESULT_LOADED`（MEM3 结果已加载）

## 注释掉的 ISR（预留扩展）

以下 ISR 已声明但未启用（在源码中注释掉）：
- `TIMA1_IRQHandler` — PWM_1 中断（当前仅作 PWM 输出）
- `TIMG7_IRQHandler` — PWM_0 中断
- `UART0_IRQHandler` / `UART1_IRQHandler` — 串口中断（当前使用轮询模式 printf）

## 中断优先级配置

| 中断 | 优先级 | 说明 |
|------|--------|------|
| ADC0 | 0（最高） | 快速采集 ADC 数据 |
| SysTick | 0（最高） | 系统时钟基准 |
| GPIOB 编码器 | 2 | 脉冲捕获（需最短延迟，但低于定时器） |
| LA 编码器 | 3 | 左编码器个别引脚稍低优先级 |

> **注**：编码器 4 个引脚中有 3 个是优先级 2，LA（PB10）是优先级 3。编码器中断不允许抢占 ADC 和 SysTick。
