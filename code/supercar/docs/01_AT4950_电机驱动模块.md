# AT4950 双路电机驱动模块

## 概述

本模块提供基于 AT4950（兼容 DRV8833）双路 H 桥电机驱动芯片的 PWM 控制接口，支持电机正反转、滑行停止和快速刹车。左电机由 TIMG7 (PWM_0) 驱动，右电机由 TIMA1 (PWM_1) 驱动。

## 硬件引脚映射

| 功能 | 信号 | MCU 引脚 | 定时器 | 备注 |
|------|------|----------|--------|------|
| 左电机 IN1 | PWM_0_C0 | PA26 | TIMG7 CCP0 | 正向 PWM |
| 左电机 IN2 | PWM_0_C1 | PA27 | TIMG7 CCP1 | 反向 PWM |
| 右电机 IN1 | PWM_1_C0 | PB17 | TIMA1 CCP0 | 正向 PWM |
| 右电机 IN2 | PWM_1_C1 | PB18 | TIMA1 CCP1 | 反向 PWM |

### PWM 配置参数

- 时钟频率：10 MHz（80MHz / 8 分频）
- PWM 周期：1000（对应 10kHz PWM 频率）
- 占空比分辨率：0~999（约 0.1% 步进）
- PWM 模式：边沿对齐（Edge-Aligned）

## 数据结构

### MOTOR_Config

```c
typedef struct MOTOR_Config {
    GPTIMER_Regs *htim1;       // 定时器实例1（正向通道）
    DL_TIMER_CC_INDEX channel1; // 通道1索引
    GPTIMER_Regs *htim2;       // 定时器实例2（反向通道）
    DL_TIMER_CC_INDEX channel2; // 通道2索引
    uint8_t reverse;            // 方向反转标志：0-正常，1-反转
} MOTOR_Config;
```

### MOTOR_t

```c
typedef struct MOTOR {
    MOTOR_Config config;  // 电机配置
    int16_t speed;        // 当前速度设定值（-999 ~ 999）
} MOTOR_t;
```

### 全局电机实例

| 变量名 | 用途 | 方向 |
|--------|------|------|
| `motorLeft` | 左电机 | reverse=0（正常） |
| `motorRight` | 右电机 | reverse=1（反转） |

## API 函数详解

### 1. Motor_ConfigInit()

**功能**：初始化电机驱动配置并启动 PWM 计数器。

```c
void Motor_ConfigInit(
    MOTOR_t *motor,             // 电机对象指针
    GPTIMER_Regs *htim1,        // 正向通道定时器（PWM_0_INST 或 PWM_1_INST）
    DL_TIMER_CC_INDEX channel1, // 正向通道索引
    GPTIMER_Regs *htim2,        // 反向通道定时器（PWM_0_INST 或 PWM_1_INST）
    DL_TIMER_CC_INDEX channel2, // 反向通道索引
    uint8_t reverse             // 方向反转标志（0=正常，1=反转）
);
```

**调用示例**（来自 main 函数）：
```c
// 左电机：TIMG7 CCP0(正向) + CCP1(反向), 不反转
Motor_ConfigInit(&motorLeft, PWM_0_INST, GPIO_PWM_0_C0_IDX,
                              PWM_0_INST, GPIO_PWM_0_C1_IDX, 0);
// 右电机：TIMA1 CCP0(正向) + CCP1(反向), 反转
Motor_ConfigInit(&motorRight, PWM_1_INST, GPIO_PWM_0_C0_IDX,
                               PWM_1_INST, GPIO_PWM_1_C1_IDX, 1);
```

### 2. Motor_SetSpeed()

**功能**：设置电机速度（含自动限幅 -999~999，负值表示反转）。

```c
void Motor_SetSpeed(MOTOR_t *motor, int16_t speed);
```

| 参数 | 说明 |
|------|------|
| `motor` | 电机对象指针 |
| `speed` | 速度值，范围 -999 ~ 999。正数=前进，负数=后退 |

**控制逻辑**：
- `speed > 0 + reverse=0`：正向旋转 → IN1=占空比, IN2=1（低电平）
- `speed < 0 + reverse=0`：反向旋转 → IN1=1, IN2=占空比
- `speed == 0`：刹车模式 → IN1=999, IN2=999

### 3. Motor_Stop()

**功能**：电机自由滑行停止（IN1=1, IN2=1，即低电平）。

```c
void Motor_Stop(MOTOR_t *motor);
```

| 参数 | 说明 |
|------|------|
| `motor` | 电机对象指针 |

### 4. Motor_Brake()

**功能**：电机快速制动（IN1=999, IN2=999，即高电平锁死）。

```c
void Motor_Brake(MOTOR_t *motor);
```

| 参数 | 说明 |
|------|------|
| `motor` | 电机对象指针 |

> **注意**：`Motor_Brake()` 将两路 IN 都设为高电平，使电机绕组短路从而实现快速制动。与 `Motor_Stop()` 的区别在于前者有制动力，后者靠惯性滑行。

### 5. Motor_Limit_Speed()（内部函数）

**功能**：对速度值进行限幅。

```c
int Motor_Limit_Speed(MOTOR_t *motor, int16_t speed, int16_t max_speed, int16_t min_speed);
```

| 参数 | 说明 |
|------|------|
| `motor` | 电机对象指针 |
| `speed` | 需要限幅的速度值 |
| `max_speed` | 最大速度（通常为 999） |
| `min_speed` | 最小速度（通常为 -999） |
| **返回值** | 限幅后的速度值 |

## 使用注意事项

1. AT4950 使用 **两路互补 PWM** 控制，不是方向+使能模式。改变方向需要调换两路 PWM 的占空比。
2. PWM 最大值为 999，对应 100% 占空比。
3. 左右电机的 `reverse` 标志用于统一坐标系：`reverse=1` 的电机，正值 speed 会让其反转。
4. PID 输出的 PWM 值通过 `Motor_SetSpeed()` 直接设置，不做额外滤波。
5. 在 `Stop_Car()` 中同时调用 `Motor_Brake()` 和 `Motor_SetSpeed(0)`，确保电机完全停止。
