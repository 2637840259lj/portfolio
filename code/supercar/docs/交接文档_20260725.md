## 关键协议约定

- 帧: [0xAA][LEN][CMD][PAYLOAD][XOR8]
- 遥测帧: 19字节, 字段顺序 gray→yaw (不再重叠)
- 航点: 12字节, [encL:4][encR:4][spd:1][act:1][timeout:2]
- 参数: 18个 (全float32 LE)
- 遥控: 油门(THROTTLE_SET) + 摇杆转向(SET_ARCADE) + 刹车(BRAKE) + 急停(EMERGENCY)
