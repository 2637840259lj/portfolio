# 系统时钟模块

## 概述

本模块提供基于 Cortex-M0+ SysTick 的系统时间基准、毫秒延时和系统时钟查询功能。SysTick 配置为 **1ms 周期**，是项目所有定时操作的基准。

## 系统时钟配置

### 时钟树核心路径

```
外部晶振 (HFXT: 40MHz)
  ↓
PLL (×4 / 4 / 1) → 80MHz
  ↓
HSCLKMUX → CPU CLK = 80MHz (CPUCLK_FREQ)
  ↓
SysTick = 80MHz / 1000 = 80000 ticks/ms
```

### SysTick 配置

| 参数 | 值 |
|------|-----|
| 时钟源 | CPUCLK（80MHz） |
| 重载值 | 80000（每 tick = 1ms） |
| 中断优先级 | 0（最高） |
| 中断使能 | 是 |

### 其他时钟分频

| 时钟 | 频率 | 用途 |
|------|------|------|
| MFPCLK | 4MHz | 外设总线时钟（80MHz / 10(HFCLK4MFPCLKDIV)） |
| ULPCLK | 2 分频 | 低功耗时钟 |
| TIMG7/TIMA1 | 10MHz | PWM 时钟（80MHz / 8） |
| TIMA0 定时器 | 100kHz | 10ms 定时中断（10MHz / 8 / 100） |

## API 函数详解

### 1. SysTick_Init()

**功能**：初始化 SysTick 为 1ms 定时器。

```c
void SysTick_Init(void);
```

**内部操作**：
- 设置 SysTick 重载值为 `CPUCLK_FREQ / 1000`（80000）
- 设置中断优先级为 0（最高）

### 2. mspm0_delay_ms()

**功能**：阻塞式毫秒延时。通过轮询 `g_system_ticks_ms` 实现。

```c
int mspm0_delay_ms(uint32_t num_ms);
```

| 参数 | 说明 |
|------|------|
| `num_ms` | 延时毫秒数 |
| **返回值** | 始终返回 0 |

### 3. mspm0_get_clock_ms()

**功能**：获取上电以来的系统运行毫秒数（SysTick 计数值）。

```c
uint32_t mspm0_get_clock_ms(void);
```

| 返回值 | 说明 |
|--------|------|
| uint32_t | 系统运行毫秒数（范围 0 ~ 约 49.7 天） |

### 4. delay_us()

**功能**：基于指令循环的微秒级延时（粗略）。

```c
void delay_us(uint32_t us);
```

| 参数 | 说明 |
|------|------|
| `us` | 延时微秒数 |

> **注意**：`delay_us()` 使用空循环实现（`us × 80` 次循环），精度依赖编译器优化等级和 CPU 频率，仅适用于非关键时序。

### 5. SysTick_Handler()

**功能**：SysTick 中断服务函数，每 1ms 递增 `g_system_ticks_ms`。

```c
void SysTick_Handler(void);
```

## 全局变量

```c
volatile uint32_t g_system_ticks_ms = 0;  // 系统运行毫秒计数器
```

此变量是项目所有非抢占式定时的基础，被以下模块使用：
- `app_imu.c`：IMU 1000Hz 更新
- `car.c`：灰度传感器 100Hz 采集
- `app_key.c`：ebtn 按键库时基
- `app_indicator.c`：LED 闪烁 / 蜂鸣器鸣叫定时
- `mpu6050.c`：I2C 超时检测
