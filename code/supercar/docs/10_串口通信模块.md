# 串口通信模块（BSP UART）

## 概述

本模块提供双路 UART 串口通信底层驱动，包括标准 `printf` 重定向（UART0）和独立的格式化输出函数（UART1）。UART0 作为调试主串口，UART1 作为辅助串口（预留给 VOFA+ 等可视化工具）。

## 硬件引脚映射

| 功能 | 信号 | MCU 引脚 | 外设 | 波特率 |
|------|------|----------|------|--------|
| 串口0 TX | UART0_TX | PA10 | UART0 | 115200 |
| 串口0 RX | UART0_RX | PA11 | UART0 | 115200 |
| 串口1 TX | UART1_TX | PA8 | UART1 | 115200 |
| 串口1 RX | UART1_RX | PA9 | UART1 | 115200 |

### UART 配置参数

| 参数 | 值 |
|------|-----|
| 总线时钟 | 40MHz |
| 波特率 | 115200（实际 115190.78，误差 0.008%） |
| 数据位 | 8 bit |
| 停止位 | 1 bit |
| 校验位 | 无 |
| 流控 | 无 |
| 过采样率 | 16× |
| IBRD | 21 |
| FBRD | 45 |

## API 函数详解

### 1. DebugUartInit()

**功能**：初始化调试串口 UART0 的中断配置。

```c
void DebugUartInit(void);
```

**内部操作**：
- 清除 UART0 中断挂起标志
- 使能 UART0 中断

> 当前版本未使用 UART 中断，而是通过 `while(DL_UART_isBusy())` 轮询方式发送。

### 2. uart0_send_char()

**功能**：通过 UART0 发送单个字符（轮询方式）。

```c
void uart0_send_char(char ch);
```

| 参数 | 说明 |
|------|------|
| `ch` | 要发送的字符 |

### 3. uart0_send_string()

**功能**：通过 UART0 发送字符串（逐字符调用 `uart0_send_char()`）。

```c
void uart0_send_string(char *str);
```

| 参数 | 说明 |
|------|------|
| `str` | 要发送的字符串指针（以 `\0` 结尾） |

### 4. fputc() — printf 重定向 ★

**功能**：重定向标准 C 库 `printf` 输出到 UART0。

```c
int fputc(int ch, FILE *stream);
```

| 参数 | 说明 |
|------|------|
| `ch` | 要输出的字符 |
| `stream` | 文件流（未使用） |
| **返回值** | 输出的字符 |

> 这是 Keil MDK 中 `printf` 的标准重定向方法。所有 `printf()` 调用都会通过此函数输出到 UART0。

### 5. UART1_Printf()

**功能**：独立的格式化输出函数，通过 UART1 发送格式化字符串（预留给 VOFA+ 等工具）。

```c
int UART1_Printf(const char *format, ...);
```

| 参数 | 说明 |
|------|------|
| `format` | printf 格式字符串 |
| `...` | 可变参数 |
| **返回值** | 输出的字符数 |

**内部实现**：
- 使用 `vsnprintf()` 格式化到 256 字节缓冲区
- 逐字符轮询 UART1 发送
- 不考虑 UART0 中断干扰

## 编译器兼容处理

为了兼容 Keil MDK 的 MicroLIB / 标准库不同配置：

```c
#if !defined(__MICROLIB)
// 不使用微库时需要定义 __stdout 和 _sys_exit()
struct __FILE { int handle; };
FILE __stdout;
void _sys_exit(int x) { x = x; }
#endif
```
