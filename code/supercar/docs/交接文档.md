## 赛道布局

```
               100cm
          A ●←──────────→● B
           /              \
          /   左弧 R=40      \   右弧 R=40
        D ●                  ● C
               ←220cm→
```

- A↔B、C↔D 之间没有黑线 → **IMU 航向直行**
- 左弧 A↔D、右弧 B↔C 有黑线 → **灰度 PID 循线**
- A↔C / B↔D 对角距离 = √(100²+80²) ≈ 128cm

## 控制架构

```
主循环 (无限速, 全速)
  ├ APP_Key_Task()         ebtn 按键处理
  ├ App_IndicatorTask()    异步 LED + 蜂鸣器
  ├ Competition_Task()     4 任务状态机
  └ 10ms 定时块:
      ├ ImuApp_Update()    姿态融合 (100Hz)
      ├ 灰度传感器采样
      └ PID_SetTarget()    写入速度目标

TIMA0 ISR (10ms):
  ├ Encoder_Update ×2      编码器速度计算
  ├ PID_Calc ×2            速度环 PID (Kp=60, Kd=0.5, FF=8.0)
  └ Motor_SetSpeed ×2      AT4950 PWM 输出

GPIO ISR:
  └ 双编码器正交解码       temp_count 累加
```

## 任务逻辑要点

### Phase_LineFollow（有黑线段）
- 灰度传感器读取归一化偏移 → 循迹 PID 输出 steer
- **找线期**: 前 800ms + 不足 1500 脉冲 → 不判丢线，直行找线
- **弧线末尾**: 70% 距离后出线 → 不失败，用 IMU coast_yaw 偏航惯性走完
- **coast 过渡**: 入 coast 后 200ms steer 平滑混合防卡顿
- Phase 切换: 距离 ≥ 目标 + 500ms

### Phase_DiagonalIMU（无黑线段）
- IMU yaw PID 航向保持 (Kp=0.8, Kd=0.15)
- 走满距离 或 扫到黑线（1/3 后）→ 进入弧线拐弯
- **弧线拐弯**: 同速直行 + yaw PID 转向，到位误差 ≤3° 或 1.2s 超时
- **拐后扫线**: 限速 25cm/s，找到黑线切下一段

## 下一步需求：位置闭环 + 速度环优化

### 问题
当前只用编码器计数做里程判断（速度环只稳速不稳位），高速时轮子打滑导致同样脉冲数实际位移不一致。任务 3 和 4 的距离参数需要分开调就是证据。

### 目标
1. **速度环优化**: 在 TIMA0 ISR 中实现完整的增量式 PID 速度闭环，用 encoder 反馈实时调节 PWM，减少打滑影响
2. **位置环 (外环)**: 在 10ms 主循环中实现位置 PID，输入 = 目标位移（脉冲），输出 = 速度目标值（送内环速度 PID）。串级控制结构：

```
目标位移 ─→ 位置PID ─→ 速度PID ─→ PWM ─→ 电机 ─→ 编码器
    ↑                                  │
    └────────── 编码器反馈 ─────────────┘
```

3. **加速制动曲线**: 加减速平滑处理（梯形/S 曲线），避免急起急停打滑
4. 位置闭环实现后，距离参数理论上不再需要区分任务 3 和任务 4，统一用理论计算值即可
5. 任务 4 的实测时间应降至 35s 以内（当前 61s）

### 修改要点
- `UserCode/UserMiddlewares/pid.c/h` — 可能需要增加位置式 PID 结构体
- `empty.c` — 10ms 块中加入位置环计算
- `UserCode/UserBsp/isr.c` — 优化速度环（已有基础，可能需要增量式改造）
- `app_competition.h` — 新增位置 PID 参数宏
- `app_competition.c` — Phase 函数中改距离判断为位置环目标设置
