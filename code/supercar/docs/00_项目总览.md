# MSPM0G3507 智能小车底盘控制系统 — 项目总览

## 项目简介

本项目是基于 **TI MSPM0G3507**（Cortex-M0+, 80MHz）开发的智能小车底盘运动控制系统，面向 **2024 电赛 H 题《自动行驶小车》**。赛道为两个对称半圆弧（R=40cm），全场 220cm×120cm，四位途经点 A、B、C、D。

系统支持双模式：竞赛 4 任务状态机 和 调试编码器闭环验证。

## 硬件平台一览

| 类别 | 型号/参数 |
|------|-----------|
| 主控 | TI MSPM0G3507（Cortex-M0+, 80MHz, LQFP-64） |
| 电机驱动 | AT4950 双路 H 桥（兼容 DRV8833） |
| 惯性传感器 | MPU6050 六轴 IMU（I2C0 总线, PA0/PA1） |
| 循迹传感器 | 8 路灰度传感器（CD4051 多路复用 + 12bit ADC） |
| 编码器 | 13 线 × 4 倍频 × 28:1 = 1456 PPR（71.30 pulse/cm） |
| 轮径 | 6.5cm（周长 20.42cm） |
| 人机交互 | 3 按键 + RGB LED + 蜂鸣器（无显示屏） |
| 调试接口 | UART1: PA8/PA9, 115200bps（printf） |
| 开发环境 | Keil MDK + TI SysConfig 1.28 + MSPM0 SDK 2.10 |

## 控制架构（位置+速度 串级闭环）

```
外环 (位置):   编码器 → 增量式位置PID → 速度目标(cm/s)
               ↑ 梯形减速剖面叠加, 两者取min

内环 (速度):   编码器 → 位置式速度PID × 2 → PWM → 电机
               ↑ (TIMA0 10ms ISR 中执行)

对角段:        IMU yaw → 位置式航向PID → steer 偏置
               无黑线时用 IMU 保持直线
```

## 双模式切换

修改两个 `#define` 即可：

| 文件 | 宏 | 1 = 调试 | 0 = 竞赛 |
|------|-----|---------|---------|
| `empty.c` 第 22 行 | `SYS_DEBUG_MODE` | 编码器闭环验证 | 4 任务状态机 |
| `app_key.c` 第 15 行 | `DEBUG_KEY_MODE` | 调试按键映射 | 竞赛按键映射 |

## 开发提示

1. **新增 .c 文件**需手动加入 Keil 工程（或编辑 .uvprojx）
2. **切换竞赛/调试模式**：改 empty.c 和 app_key.c 的两个 `#define`
3. **SWD 冲突风险**：UART0 占用 PA10/PA11（SWDIO/SWCLK），如 syscfg 重新生成会导致 JLink 连不上
4. **printf 走 UART1**（PA8/PA9），不是 UART0
5. **IMU 零偏已硬编码**：gyroBias={0,1,30}, accelBias={740,270,-184}
6. **灰度白校准**：Key1 长按 2s（仅空闲时有效）
